# Import/Export Groups

*[English version](README.md)*

Расширение для Blender, которое раскладывает пункты **File > Import** и **File > Export** по
вашим собственным именованным группам, каждая — отдельное подменю: «Photogrammetry»,
«Flat formats», «FBX for Unreal» — как удобно в работе.

Каждый установленный аддон добавляет в эти меню свои пункты, и со временем они превращаются в
длинный плоский список. Расширение меняет только то, как этот список устроен:

- Пункт, добавленный в группу, **переносится** в её подменю (а не дублируется).
- Всё, что вы не сгруппировали, остаётся на месте, в исходном порядке.
- Клик по пункту запускает оригинальный импортер/экспортер с его обычным окном выбора файла и
  настройками. Никаких пресетов и обёрток.
- У Import и Export — независимые списки групп.

## Требования

Blender **4.2 или новее** (формат extensions). Проверено на 4.5 LTS и 5.2 LTS.

## Установка

1. Скачайте `import-export-groups-<версия>.zip` со страницы
   [Releases](https://github.com/Burn10110/blender-import-export-grouping/releases).
2. В Blender: **Edit > Preferences > Add-ons**, меню **⌄** справа вверху >
   **Install from Disk...**, выберите zip. Можно и просто перетащить zip в окно Blender.
3. Убедитесь, что **Import/Export Groups** включён в разделе **Add-ons**.

## Использование

Откройте **Edit > Preferences > Add-ons > Import/Export Groups** и разверните его.

- Вкладки **Import / Export** переключают меню.
- В списке — ваши группы с их пунктами, затем **Other entries**: всё, что сейчас есть в меню и не
  входит в группы.
- **+** добавляет группу после выделенной. Двойной клик по группе — переименование.
- **−** удаляет выделенную группу (её пункты снова становятся несгруппированными) или убирает
  выделенный пункт из группы.
- **→** (Send to Group) переносит выделенный пункт в существующую группу, в новую
  (**New Group**) или обратно в несгруппированные (**Ungrouped**).
- **▲ / ▼** двигают выделенную группу или пункт. Пункт, сдвинутый за край своей группы,
  переходит в соседнюю; сдвинутый вниз из последней группы — становится несгруппированным.
- Поле поиска фильтрует список по имени.

Каждое изменение сразу сохраняется и применяется: кнопки Save нет, перезапуск не нужен.

В меню группы идут сверху в заданном порядке, за ними разделитель и остальное штатное меню.

### Если аддон выключен

Если пункт принадлежит аддону, который сейчас выключен или удалён, он пропускается в меню, а в
настройках помечается **(not available)**. Из группы он не удаляется и вернётся, когда аддон
снова включат. Группа, в которой нет ни одного доступного пункта, не показывается.
Пункты аддонов, установленных позже, появляются несгруппированными в обычном списке.

### Перенос групп на другую машину

- **Export JSON...** сохраняет все группы Import и Export в файл.
- **Import JSON...** заменяет все группы группами из файла (с подтверждением; прежний файл
  сохраняется как `groups.json.bak`).
- **Open Config Folder** открывает папку с `groups.json` — файлом, где хранятся группы.
  Он лежит в пользовательской папке расширения Blender, отдельно от файлов самого расширения.

### Отключение

Отключение расширения сразу возвращает штатные меню. Группы остаются в `groups.json` и
применяются снова при повторном включении.

## Ограничения

- Один уровень групп, без вложенных подменю.
- Группы только переставляют пункты и не хранят настройки операторов (для этого есть пресеты
  самих операторов или Collection Exporters в Blender).
- Обрабатываются только File > Import и File > Export.
- Если другой аддон целиком подменяет функцию отрисовки этих меню (а не добавляет пункты через
  append, как обычно делают аддоны) и загружается после этого, группы могут не появиться.

## Сборка из исходников

```
blender --command extension build --source-dir import_export_groups --output-filepath dist/import-export-groups-1.0.0.zip
```
